# Musicplayer
Little program to open a browser to play music. Currently only compatible with ytmusic. 

The (planned) main will open up a GUI. First action would be to add a new Playlist and give it a tag, with which the playlist gets chosen.
After at least one is added, you can then type said tag in the "searchbar", add if you want the playlist shuffled, press enter and the browser gets opened.

The GUI can be resized to a user specific size with the buttons and searchbar adapting. Window can also be reset to original size.

Predeterment hotkeys can be changed by the user to a combination they need. 

Playlists can be added and removed via a Settings window.

Since the Hide button also hides the programm from the taskmanager, a warning shows up at the first use to tell you what hotkey lets it reappear.
The message can be set to pop up again or be disabled entirely.
